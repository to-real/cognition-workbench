# Product model

## Positioning

Cognition Workbench is a system that proposes valuable topics, guides users through incremental discussion, preserves the resulting judgments, and recalls them in later work for validation or challenge.

## Value

External information can often be found again. A durable cognition system preserves what is harder to reconstruct:

- how a judgment was formed;
- which evidence supported or challenged it;
- what changed the user's mind;
- which frameworks transfer to another problem;
- which blind spots repeatedly appear.

## Four moments of value

1. **Before discussion:** discover a worthwhile question and connect it with existing cognition.
2. **During discussion:** offer a small amount of framing, counterevidence, and cross-topic recall.
3. **After discussion:** consolidate a topic overview, reusable cognition units, evidence, and open questions.
4. **During other work:** recall genuinely relevant cognition without requiring a special prompt.

## Default AI role

The AI acts as a research facilitator. It builds a provisional topic map, locates evidence, asks focused questions, identifies contradictions, and recalls earlier judgments. It does not rush to provide a final answer. Analyst, critic, and summarizer are temporary roles used only when useful.

## First-release validation

The initial release validates one complete loop:

user-selected topic → guided discussion → reviewed consolidation → contextual recall in another Codex task → new evidence or judgment → review candidate.

Success is measured by whether prior cognition improves later work, not by the number of saved files.
