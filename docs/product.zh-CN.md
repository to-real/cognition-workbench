# 产品说明

## 一句话定位

认知工作台是一个会主动选题、通过引导式讨论帮助使用者形成判断，并能在未来工作中调用旧观点继续验证和质疑的个人认知系统。

## 核心价值

知识库的价值不是保存更多资料，而是让过去形成的认知参与今天的思考。

外部资料可以重新搜索，认知系统需要长期保存：曾经如何理解、依据是什么、哪些判断被修正、哪些框架可以迁移、哪些盲点反复出现。

## 四个价值时刻

1. 讨论前：发现值得研究的问题，连接旧认知。
2. 讨论中：提供少量引导、反证和跨议题呼应。
3. 讨论后：沉淀议题总览、认知单元、证据和未决问题。
4. 其他工作中：无需额外提示，主动调用真正相关的个人认知。

## 默认角色

AI 是研究主持人。它负责搭建议题地图、提供材料、提出问题、发现矛盾和调用旧认知，但不抢着给出标准答案。分析师、反方辩手和总结者是按需切换的临时角色。

## 第一版验证目标

第一版只验证一条完整链路：

人工点题 → 引导讨论 → 确认沉淀 → 切换到其他 Codex 工作 → 自动调用相关认知 → 完成当前工作 → 提出新的认知候选。

成功不以文件数量衡量，而以旧认知是否在新任务中产生有用影响衡量。

## 每日机制

系统每天推荐一个候选议题。当天重要事件优先；没有重大事件时，选择长期高价值问题；旧认知出现矛盾、过时或缺口时，优先安排复核。

候选议题必须由使用者决定是否启动。
