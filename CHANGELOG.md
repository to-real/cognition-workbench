## [0.1.0] - 2026-08-05

### Added

- Three Codex skills for guided discussion, contextual recall, and one daily topic.
- A local MCP server with nine tools for retrieval, relationships, review candidates, confirmation, status, and daily topics.
- Markdown knowledge templates and a review-before-write workflow with revision history.
- Portable, non-destructive Codex installation with a dry-run mode.
- Unit and integration coverage, including a real MCP client/server exchange.
- Bilingual project documentation and open-source community files.
